# Calculatrice JavaScript

## Description
Ce projet est une calculatrice web simple développée avec HTML, CSS et JavaScript. Elle permet d'effectuer des opérations mathématiques de base et de consulter l'historique des calculs.

## Fonctionnalités
- Addition, soustraction, multiplication et division.
- Calcul du pourcentage.
- Affichage des résultats.
- Sauvegarde de l'historique des calculs avec `localStorage`.
- Interface simple et intuitive.

## Technologies utilisées
- HTML5
- CSS3
- JavaScript
- LocalStorage

## Installation et utilisation
1. Clonez ou téléchargez ce dépôt GitHub.
2. Ouvrez le fichier `index.html` dans votre navigateur.
3. Utilisez la calculatrice pour effectuer vos calculs.
